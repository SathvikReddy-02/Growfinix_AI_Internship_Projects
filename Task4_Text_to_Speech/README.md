\# Growfinix Task 4 — AI Text-to-Speech Generator



\## Overview

A Python desktop application that converts user-entered text into natural-sounding speech and saves the generated audio as an MP3 file.



Users can enter text, select a voice and generate speech using Microsoft's Edge Text-to-Speech service.



\## Features

\- Convert text into speech.

\- Select from multiple available voices.

\- Generate audio in MP3 format.

\- Save generated audio files.

\- Automatically open the generated audio for playback.

\- Simple graphical user interface.



\## Technologies Used

\- Python 3

\- Tkinter

\- Edge-TTS

\- Microsoft Edge online Text-to-Speech service



\## Installation

Install the required package:



```bash

pip install edge-tts

```



\## How to Run

Run the following command:



```bash

python text\_to\_speech.py

```



1\. Enter the text in the application.

2\. Select a preferred voice.

3\. Click Generate Speech.

4\. Choose where to save the MP3 file.

5\. Play the generated audio.



\## Available Voices

\- en-US-AriaNeural

\- en-US-GuyNeural

\- en-GB-SoniaNeural

\- en-IN-NeerjaNeural

\- en-IN-PrabhatNeural



\## Implementation Note

The application uses the Edge-TTS Python package to access Microsoft's online speech synthesis service. An internet connection is required for speech generation.
